  - 정식 운영 판정은 골든 평가 실행 결과(통과인데 오답 0%, 금지 주장 0건)를 본 뒤에 내리기를 권합니다(7장).

## 3. 검색 품질 평가 (오프라인, API 비용 없음)

`src/lib/retrieve.eval.test.ts`는 실제 지식베이스(docs + qa)에 대표 문의 26건을 넣고, 기대 문서가 근거 상위 10개 안에 드는지 측정합니다. 회귀 테스트로 상시 실행됩니다.

| 영역 | 건수 | 기대 문서 순위 |
|---|---|---|
| API 사용법 | 5 | 1, 1, 1, 1, 1 |
| 가이드 | 6 | 1, 1, 1, 1, 2, 1 |
| 약관·정책 | 5 | 5, 1, 9, 1, 4 |
| 콘테스트 운영 | 4 | 1, 1, 1, 1 |
| AI Toolkit | 2 | 2, 1 |
| 과거 공식 답변 | 2 | 2, 1 |
| 원문 그대로 (영어·중국어 번체) | 2 | 1, 1 |

- 결과: **hit@10 = 1.00 (26/26), MRR = 0.85**, 검색 1회 0.7 ms (청크 7,761개)
- 약점: 약관·정책 문서는 4~9위로 순위가 낮습니다.
- 한계: 문항을 개발자가 문서 제목을 알고 만들었으므로 결과가 **낙관적으로 편향**되어 있습니다.
